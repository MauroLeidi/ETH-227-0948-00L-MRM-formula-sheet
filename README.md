# ETH-227-0948-00L-MRM-formula-sheet
Formula cheat sheet to memorise before the oral exam.

Formula sheet for ETH course 227-0948-00L Magnetic Resonance Imaging in Medicine.

Public-safe files:

- `output/pdf/mri_full_course_formula_sheet.md` - editable Markdown formula sheet
- `scripts/build_formula_sheet_pdf.py` - builds a PDF from the Markdown

The original lecture PDFs, scanned notes, extracted text, rendered scratch files, and generated PDFs are intentionally ignored by git.

Build the PDF:

```bash
python3 scripts/build_formula_sheet_pdf.py output/pdf/mri_full_course_formula_sheet.md
```

The PDF is written to `output/pdf/mri_full_course_formula_sheet.pdf`.
